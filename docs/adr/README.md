# Архитектурные решения (ADR)

Здесь записываются решения, которые трудно отменить: новые зависимости, изменения
архитектуры модулей, выбор режима перехода по умолчанию.

- Один файл — одно решение: `NNNN-краткое-название.md`, номера по порядку.
- Шаблон: [`0000-template.md`](0000-template.md).
- Принятое решение не переписывается; если оно меняется, пишется новый ADR со ссылкой на старый.
